# city-247 — every district works around the clock, honestly

One job: each district has its own queue of approved work, Heisenberg runs it every few minutes on the server,
and every district shows RUNNING, BLOCKED (with the exact question) or IDLE. Never faked activity.
Owner decisions (2026-10-15 grill-me): the CitySpec is the one district list; queues are GitHub issues labeled
`district:<id>`; first lanes Production, Impact (NW Kids Google profile + Google nonprofit grants), Commerce
(Freedom of Speech store, test-only); free models first, paid capped per lane; one self-hosted Supabase.

## How it runs (the loop)
1. Owner or a lead opens an issue in `executiveusa/pauli-starnet` labeled `district:<id>`; adds `approved` to let it run.
   Labels `perm:<name>` declare permissions (default `research`); anything outside the district's unattended set blocks.
2. `deploy/systemd/starnet-foreman.timer` runs `scripts/district/foreman.js` every 5 minutes: settle finished
   missions, read queues, decide (`sidecar/district-foreman.js`), dispatch through the gateway mission desk with the
   district's cited knowledge in the brief, write the board.
3. The crew's result is commented on the issue and labeled `needs-review`; the independent reviewer says SHIP or HOLD.
4. `GET /v1/districts` (gateway bearer) shows each district; a board older than 15 minutes says `stale: true`.
