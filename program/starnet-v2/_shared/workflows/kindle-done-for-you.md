# Done-for-you Kindle publishing: workflow

Offer: the client hands over a manuscript (usually a PDF). The city returns a professionally edited, KDP-ready ebook (+ optional paperback),
with a cover proposed and refined with the client, and the client walks away published. Facts below were checked 2026-10-25 against Amazon's
KDP help pages; re-check before each new client, because KDP rules change.

Mission template district: **revenue** (delivery), with **creative** (cover) and **command** (approvals). Every step carries a persona from the library.

| # | Step | Who | Gate |
|---|---|---|---|
| 1 | **Intake.** Receive the file. Record title, author name, genre, target reader, word count, ebook/paperback, deadline | Instinct ↔ client | — |
| 2 | **Extract.** PDF → clean text (keep headings, lists, images, footnotes). Flag anything unreadable | agent | — |
| 3 | **Rights + content check.** Is it theirs to publish? Any third-party text or images, trademarks, medical/financial claims? Note what needs the client's answer | agent | red if unclear |
| 4 | **Edit pass 1: mechanics.** Grammar, punctuation, spelling, consistency (names, tense, numbers), with a tracked-changes copy. AI-*assisted*: no KDP AI disclosure needed for this | editor persona | — |
| 5 | **Edit pass 2: readability.** Structure, chapter flow, repetition. Suggestions only, never rewriting the author's voice without consent | editor persona | — |
| 6 | **Client review loop.** Send the tracked changes; the client accepts or rejects; repeat until approved (max rounds set at intake) | Instinct ↔ client | yellow per send |
| 7 | **Front + back matter.** Title page, copyright page, table of contents, dedication, about the author, call to action | agent | — |
| 8 | **Format the ebook.** EPUB (preferred) or DOCX; real heading styles; linked TOC; images inline with alt text. Check on a Kindle previewer | agent | — |
| 9 | **Format the paperback (optional).** Trim size (6×9 or 5.5×8.5 are the most common), margins ≥ 0.5" with a larger gutter, PDF with exact trim; page count → spine width | agent | — |
| 10 | **Cover concepts.** 3 directions from the genre + reader brief using image models; title and author set with real typography afterwards (no AI-drawn text). Ebook: 2560×1600 px ideal (1.6:1), min 1000×625. Paperback: 300 DPI, full wrap = back + spine + front with 0.125" bleed | creative persona (Opus only if the captain says so) | yellow per send |
| 11 | **Cover review loop.** Client picks a direction → 2 refinement rounds → final files | Instinct ↔ client | — |
| 12 | **Metadata pack.** Title/subtitle, description (sales copy, the-extractor slop check), up to 7 keywords, categories, age range, language, price suggestions with the royalty rules explained (35%/70% options; the 70% band has a price range), KDP Select pros and cons | agent | client decides price |
| 13 | **AI disclosure sheet.** Mark what's AI-*generated* (e.g., an AI cover = must disclose) vs AI-*assisted* (editing = no disclosure). Failing to disclose risks removal | agent | — |
| 14 | **KDP setup guide.** The client creates **their own** KDP account, tax interview and bank details (we never hold their credentials); then Create Title → details → content → pricing, step by step with screenshots | Instinct ↔ client | red: the client clicks Publish |
| 15 | **Final QA.** Open the files on a Kindle app/previewer and check TOC links, images, cover thumbnail legibility, spelling of the name and title | QA persona (different model family) | judge |
| 16 | **Hand-off + follow-up.** Deliver final files + metadata pack + disclosure sheet; after going live, check the listing and offer a launch checklist | Instinct | — |

Deliverables: edited manuscript (tracked + clean), EPUB/DOCX, paperback PDF (optional), cover files (ebook JPG/TIFF, paperback PDF wrap),
metadata pack, AI disclosure sheet, KDP setup guide. Red throughout: the Fiverr listing, messages to buyers (yellow per send after the
captain approves the offer), payments, and the client's Publish button.
