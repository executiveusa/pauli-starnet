# 02_intake-and-inbox

**One job:** One gateway inbox for Instinct + command center; factory intake queue (max 5/day) with a grill record per repo.

**Owner:** architect (routes + tests), builder (Instinct wiring)

**Done when:** Proof = tests + a live intake from Instinct showing in the queue; the 6th intake refused.

Evidence goes in `output/EVIDENCE.md` (shape: `../../starnet-v1/CONTEXT.md`). The builder never sets `verified_by` on its own work.
