# Diagnostic order

1. **Demand:** weak impressions across sound packages may mean the idea/audience is wrong.
2. **Choice:** impressions without clicks means title/thumbnail mismatch or weak differentiation.
3. **Consumption:** clicks with early drop means hook/promise delivery; later drop means structure/value density.
4. **Conversion:** useful watch with no next action means offer/CTA/audience fit or tracking failure.

Never diagnose from one metric alone. Record sample size and uncertainty. Change one main variable per test.

Evidence rule: these diagnostics implement a creator framework, not independently verified causation. Label each diagnosis a hypothesis until first-party tests support it.
