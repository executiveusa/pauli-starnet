# YouTube System Agent - workspace map

Form: Context map + Umbrella of four pipelines + Knowledge bundle corpus.

| Workflow | Repeating unit | Product |
|---|---|---|
| `01_methodology-maintenance` | one evidence update | approved methodology revision |
| `02_client-channel` | one client/channel run | approved, measured client video |
| `03_faceless-channel` | one faceless episode | approved, rights-cleared video package |
| `04_brand-training` | one learner/cohort | certified operator or remediation plan |

All production workflows consume `[[data-operating-philosophy]]`. Client and faceless production share principles, but never share working output folders. The filesystem is the state machine: a stage is complete only when its `output/` contains its named artifact and its gate record.
