# 04_sandbox - produce a practice package

One job: run a non-public practice brief through research, package and script stages.

## Inputs
- Working: `../../_templates/sandbox-brief.md`
- Reference: `../../../../_shared/brand/brand-system.md` and `../../../02_client-channel/CONTEXT.md` as the default practice contract

Do NOT load: other workflows' run outputs or the whole corpus.

## Process
1. Read only the named inputs.
2. Do this stage's one job and record evidence/uncertainty.
3. Write the named artifact and a gate record.

## Outputs
- sandbox-package.md → output/
- gate.md → output/

## Human check
Trainer scores audience fit, evidence, package truth, promise delivery, originality and audit trail. Edit the artifact in place; the next stage reads the approved version.
