# Playbook: per-model prompt formulas (nodes veo-5-part-formula, kling-director-formula, json-prompt-framework)

## Veo 3.1 (five parts, in order)
1. Camera movement + lens ("low-angle truck left", "slow dolly in", anamorphic, macro 100mm) - must imply movement.
2. Subject + physics - secondary motion (hair, water, vibration). Veo needs physics to look real.
3. Lighting + atmosphere - volumetric fog, subsurface scattering, gobo lighting.
4. Audio engineering - foreground (action), mid-ground (dialogue/movement), background (ambience).
5. Technical tokens - 8k, temporal coherence, photorealistic, cinematic color grading.

## Kling 3.0 (director style)
Subject + Action + Setting + Camera + Style, in explicit shot language (profile shot, macro close-up, tracking, shot-reverse-shot). Native multi-shot: storyboard [Shot 1]-[Shot 6] with continuity. Native audio/dialogue cues ("Man speaks: ..."). Lock the core subject + environment at the top for consistency.

## Nano Banana (image)
Ask for prompts in a detailed JSON structure; store the JSON as reusable templates.
