# Playbook: realism doctrine (node realism-mandate) - gauntlet vocabulary

"Captured, not created." Every realism-scored prompt embeds:

- CAMERA SYSTEM (rotate): ARRI ALEXA 35, ARRI ALEXA Mini LF, RED V-RAPTOR 8K (IMAX 65mm only when scale demands).
- LENS: ARRI Signature Prime, Cooke S4/S7, Panavision Primo/Ultra Vista. Explicit focal length (35/40/50mm) + aperture (T2.8-T4).
- IMPERFECTION: grain, uneven exposure, imperfect focus, natural focus roll-off. Plastic skin, glow, CGI sharpness = fail.
- LIGHT: physically motivated only.
- GENRE SETS: documentary = flat contrast + handheld micro-sway; sci-fi = practical motivated sources, cooler sensor; horror = motivated darkness + sensor noise; dystopian = desaturated + harsh practical; fantasy = firelight/overcast, earth tones.
- MODES: MOVIE_SET (crew/rigging allowed) vs STILLS_ARCHIVE (pure in-world still).

Source: metricsmule.com/ai/ai-video-prompt-engineering (Cinematic Movie Studio PG prompt). The gauntlet critic scores Realism against this list.
