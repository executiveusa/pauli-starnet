# Playbook: Seedance structure (nodes seedance-structure, reference-stacks, moderation-playbook)

Law for every Seedance scene we author:

1. TIMESTAMPS per shot block - never one flowing paragraph.
2. GLOBAL LOCK first line: tag the character + reference image ("global lock: [character], [image]"). Character lock per scene for who is on screen.
3. ONE camera movement per timestamp block. Two movements = split into two blocks.
4. REFERENCE STACK: tag product and location images too; Seedance accepts up to 50 references. Yappyverse 16-image character packs are the standing reference sets.
5. LENGTH: long and structured beats short and clever.

Pre-flight (moderation): prompt must read like a filmmaker describing a shot, not a note to a friend. No real identifiable faces (celebrities, politicians, even self), no named copyrighted/trademarked IP in client work. If flagged, rewrite in production language - do not thesaurus-hunt single words.
