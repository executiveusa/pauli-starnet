# Source Catalog

Use these sources to prepare human-facing options. “Open source” software and “open asset” libraries are distinct; each candidate still needs its own license ledger.

| Need | Catalog / project | License decision |
| --- | --- | --- |
| WebGL runtime | [three.js](https://github.com/mrdoob/three.js), [React Three Fiber](https://github.com/pmndrs/react-three-fiber), [Drei](https://github.com/pmndrs/drei) | inspect dependency license |
| Effects | [react-postprocessing](https://github.com/pmndrs/react-postprocessing) | inspect dependency license |
| glTF processing | [glTF-Transform](https://github.com/donmccurdy/glTF-Transform), [glTF Validator](https://github.com/KhronosGroup/glTF-Validator), [Sample Assets](https://github.com/KhronosGroup/glTF-Sample-Assets) | provenance per asset |
| Compression | [meshoptimizer](https://github.com/zeux/meshoptimizer), [KTX-Software](https://github.com/KhronosGroup/KTX-Software), [Basis Universal](https://github.com/BinomialLLC/basis_universal) | inspect dependency license |
| Humanoid format | [three-vrm](https://github.com/pixiv/three-vrm), [VRM specification](https://github.com/vrm-c/vrm-specification) | model license separate |
| Avatar authoring | [Blender](https://github.com/blender/blender), [MakeHuman](https://github.com/makehumancommunity/makehuman), [MB-Lab](https://github.com/animate1978/MB-Lab) | MB-Lab needs copyleft review |
| Worlds/materials | [Poly Haven](https://polyhaven.com/license), [ambientCG](https://ambientcg.com/list?type=Material) | record source asset terms |
| Props / 2D packs | [Kenney](https://kenney.nl/assets), [Quaternius](https://quaternius.com/) | record pack terms |
| Audio | [Freesound](https://freesound.org/) | per-sound license and attribution |

Provider adapters such as Meshy are not open source. Use them only after cost, output rights, and owner approval are recorded.
