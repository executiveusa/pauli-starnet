# Five offline draft rooms built from Nick's Stack

This is a private scaffold, not a deployed fleet. Source template: https://github.com/nickvasilescu/nicks-stack at `90b9975c5391591e98565d20d33554a6b91f2f85`. `build.js` reads that template's `files/config.yaml` and `files/SOUL.md`, and renders five isolated draft room configurations, retaining Nick's MCP/plugin/secret plane but switching the default paid Nous route to `openai-codex` OAuth. It deliberately does not copy any auth material or connect to Orgo. Nick's default requires Nous credits; Orgo's launch requires a paid plan. Neither is authorized by a subscription request.

Example offline proof: `node districts/crypto-cuties/nicks-stack/build.js ../nicks-stack /tmp/cuties-draft-rooms`; `node --test test/cuties-nicks-stack.test.js`. Generated configs are local, not running agents. Do not put generated rooms or secrets in git.

Memory: `schema.sql` is an unapplied PostgreSQL migration, scoped by `cuties.agent_id` transaction-local setting and forced RLS. `runtime.js` exposes parameterized append/recall calls using an injected Postgres pool; no database endpoint or live connectivity is claimed. Provision a separate no-BYPASSRLS, non-owner role before use, with `USAGE` on schema, `SELECT` on agents, `SELECT, INSERT` on memory and identity sequence use, but no update/delete. Because any caller using one shared DB role could forge the session setting, separate roles/connection pools or a trusted manager-only memory API are required before letting an agent issue raw SQL. Restrict memory body to approved facts, never credentials or unreviewed personal data. Set retention, delete and correction policies before keeping real information. "Remember everything" cannot literally promise complete or perpetual memory.

Dispatch: `prepare` emits a HELD envelope labelled for Hermes; it does not call Hermes. Wire only to an authenticated, owner-governed Hermes intake after verifying the live route. The StarNet repo's `/v1/intents` design is still a proposal, not a proven live endpoint. All four marketplace/social lanes have draft-only envelopes; no external account/login, bid, post, listing, product charge or platform automation is connected. Confirm marketplace account and AI/disclosure rules before enabling any lane. The five room IDs are stable, but roster candidates in `manifest.json` are not published identities and remain held pending the women, likeness, and rights decisions.
