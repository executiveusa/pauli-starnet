### 1. Churn Rescue Trigger

JEV watches customer usage signals and decides whether to fire a retention action — before the cancellation request ever arrives.

**Typed questions:**
- `churn_risk_class` (safe / watch / imminent)
- `rescue_action` (none / auto_discount_15 / human_call / let_go)
- `recheck_after_days` (integer)

**Money lane:** Retained MRR. If 3 customers/month are rescued at $299 AI-employee SKU = ~$9K MRR preserved annually. Cheaper than acquisition.

**Cost-to-try:** Free floor — export last 90 days of login/call-usage CSV from your dashboard, run JEV shadow classifications in a sheet. No API spend.

**Smallest proof mission:** Pull 20 existing customers. JEV scores each on churn_risk_class. Compare against your gut label. If ≥5/6 agreement on the "imminent" bucket, wire the auto_discount_15 path to a Stripe coupon ID and shadow-test on the next 2 flagged accounts.

### 2. Refund Triage Gate

JEV decides approve, deny, or escalate on inbound refund/chargeback requests — typed decision, no prose drafting.

**Typed questions:**
- `refund_reason_class` (product_fail / buyer_remorse / fraud_signal / billing_error / noise)
- `refund_decision` (auto_approve / deny / escalate_human)
- `fraud_confidence` (0–1)

**Money lane:** Denied illegitimate refunds + faster auto-approve on clean billing errors (reduces support load and chargeback fees). Even 2 denied $299 refunds/month = $7K/yr saved.

**Cost-to-try:** Free floor — last 50 refund requests as CSV (reason text + outcome). JEV shadow-decides; compare to actual human outcomes.

**Smallest proof mission:** Run JEV on 50 historical refunds. Measure agreement with human final decisions. If fraud_confidence > 0.7 correlates with chargeback losses, draft the deny-path rule for owner approval.

### 3. Content Repurpose Router

JEV decides which owned content assets get repurposed to which platforms — and which die. No copy generation; routing only.

**Typed questions:**
- `asset_quality_score` (0–1)
- `repurpose_target` (linkedin / x / instagram / kill)
- `urgency_class` (evergreen / timely / stale)

**Money lane:** More reach per asset without extra production cost. A single well-routed long-form piece = 4 posts instead of 1, feeding the Postiz loop from Seed 4.

**Cost-to-try:** Free floor — 10 existing blog/video transcripts as text. JEV scores and routes. No spend.

**Smallest proof mission:** Feed 10 assets. JEV assigns repurpose_target. Manually post the top 3 routed pieces per JEV's target. Track 7-day engagement vs your usual platform-default picks.
