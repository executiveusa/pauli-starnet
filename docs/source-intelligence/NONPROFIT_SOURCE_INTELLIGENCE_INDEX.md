## Verification boundary

The source package contains numerous time-sensitive or high-stakes claims about fundraising outcomes, donor behavior, grant screening, legal remedies, credit availability, lender terms, loan approval, income potential, platform fees, and time-to-result. These claims are research leads, not StarNet truth.

Before client use:

1. identify the source claim and prerequisites;
2. separate claim, opinion, example, and tactic;
3. verify current legal, financial, platform, eligibility, and outcome-sensitive facts against authoritative sources;
4. store the verification result with the source record;
5. only then convert supported recommendations into an executable mission.
